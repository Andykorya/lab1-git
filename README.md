# Проєкт: Супер Менеджер (Версія Feature)

Це мінімально життєздатний продукт (MVP) для керування щоденними завданнями, який допомагає користувачам фокусуватися на головному.

## 🚀 Основна ідея
Проєкт створений для того, щоб спростити планування робочого дня за допомогою пріоритезації задач. Це допомагає уникнути вигорання та підвищити продуктивність. 

## 🛠 Стек технологій
У проєкті використовуються наступні інструменти:
* **HTML5 / CSS3** — структура та дизайн.
* **JavaScript** — логіка роботи списку задач.
* **Git** — контроль версій.
